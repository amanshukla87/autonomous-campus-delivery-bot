# AprilTag Navigation Test Images

This directory is reserved for photographs documenting the AprilTag navigation tests.

| File | Description |
|---|---|
| `apriltag_id1_test_side.jpg` | Side-view test photograph showing Tag ID 1 |
| `apriltag_id1_test_top.jpg` | Top-view test photograph showing Tag ID 1 |

Use the tag ID in filenames and captions rather than assigning a direction based on handwritten labels on the printed sheet. In the current navigation mapping, Tag ID 1 commands a right turn.

No ID 40 action is implemented by the current Raspberry Pi script. If an ID 40 test photograph is retained, label it as an extra test tag with no action assigned.
