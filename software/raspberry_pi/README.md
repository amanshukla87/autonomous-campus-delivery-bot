# Raspberry Pi Software

This directory contains the high-level application intended to run on the Raspberry Pi.

## Files

- `main.py` — AprilTag detection and serial command handling.
- `config.py` — Configuration for tag IDs, associated commands, and serial connection settings.
- `requirements.txt` — Python package dependencies.
- `tools/generate_apriltags.py` — Optional utility for generating printable AprilTag images.

The application source and configuration will be added or completed using the project's verified implementation. No unverified pin assignments, serial settings, or navigation behaviour are assumed here.
