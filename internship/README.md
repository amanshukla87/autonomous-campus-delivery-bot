# Internship

## Kalam Pragati MakeX Internship 2025

This folder contains documentation and selected records from the **Kalam Pragati MakeX Internship 2025 – Autonomous Robotics**, organised by the **ERA Foundation in collaboration with Dr. A.P.J. Abdul Kalam Technical University (AKTU)**.

### Project

**Autonomous Campus Delivery Bot**

The project focused on developing an autonomous mobile robot for campus delivery. The system combined camera-based AprilTag detection on a Raspberry Pi 5 with Arduino-based motor control and ultrasonic obstacle monitoring.
