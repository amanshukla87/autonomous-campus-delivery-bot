# Hardware Documentation

This directory contains the hardware design and implementation documentation for the Autonomous Campus Delivery Bot.

## Contents

The following documents and diagrams will be added as the project hardware documentation is completed:

- `bill_of_materials.md` — Components and hardware specifications.
- `wiring_and_pinout.md` — Connections and pin assignments.
- `block_diagram.png` — Hardware system block diagram.
- `circuit_diagram.png` — Circuit-level wiring diagram and, where available, its editable source.
- `chassis_and_mounting.md` — Chassis layout and component mounting details.

Only verified components, connections, and design details will be documented here.
